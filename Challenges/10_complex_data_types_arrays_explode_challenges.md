# PySpark Challenge 12: Complex Types, Arrays, and Explode (Easy to Complex)

**The Setup:**

You are analyzing e-commerce transactions. The data comes in with the user's purchased items stored as a single comma-separated text string. You also have a separate catalog table with product prices.

Copy the following code into your notebook to generate the mock DataFrames.

```python
from pyspark.sql.types import StructType, StructField, LongType, StringType, DoubleType
from pyspark.sql.functions import col, split, explode, size, array_contains, sum, when

# 1. Transactions Data (Purchases stored as a single string)
txn_schema = StructType([
    StructField("txn_id", LongType(), True),
    StructField("user_id", StringType(), True),
    StructField("purchased_items", StringType(), True)
])

txn_data = [
    (101, "User_A", "laptop,mouse,keyboard"),
    (102, "User_B", "monitor"),
    (103, "User_C", "mouse,cable,webcam"),
    (104, "User_A", "webcam,laptop")
]
txn_df = spark.createDataFrame(data=txn_data, schema=txn_schema)

# 2. Product Catalog Data
catalog_schema = StructType([
    StructField("product", StringType(), True),
    StructField("price", DoubleType(), True)
])

catalog_data = [
    ("laptop", 1200.00),
    ("mouse", 25.50),
    ("keyboard", 75.00),
    ("monitor", 300.00),
    ("cable", 15.00),
    ("webcam", 60.00)
]
catalog_df = spark.createDataFrame(data=catalog_data, schema=catalog_schema)

print("Transactions DF:")
txn_df.show(truncate=False)
print("Catalog DF:")
catalog_df.show()
```

## Challenge 12a: Splitting and Sizing (Easy)

**Task:**

Create a new DataFrame from `txn_df`.

1. Add a column called `items_array` that splits the `purchased_items` string into a real PySpark Array (split by comma `,`).
2. Add a column called `item_count` that calculates the `size()` of the new `items_array`.
3. Show the resulting DataFrame.

## Challenge 12b: The Explode Filter (Medium)

**Task:**

Create a new DataFrame.

1. Use `split()` to convert `purchased_items` to an array, and immediately `explode()` that array into a new column called `single_item`.
2. Filter the DataFrame to ONLY show rows where the `single_item` is `"webcam"`.
3. Select `txn_id`, `user_id`, and `single_item` and show the DataFrame.

## Challenge 12c: The Revenue Engine (Boss Level)

**Task:**

The business wants to know the total revenue generated by each user, and they want to assign a VIP status to big spenders. This requires combining Arrays, Joins, Aggregations, and Conditionals!

Write a single chained PySpark pipeline that does the following:

1. **Array Conversion & Explode (Part 12):** Create an array from `purchased_items` and `explode` it into a new column called `product`.
2. **Join (Part 6):** Join the exploded DataFrame with the `catalog_df` on the `product` column to bring in the `price` for each item.
3. **Aggregate (Part 4):** Group the data by `user_id` and calculate the `sum` of the `price`. Alias this new column as `total_spent`.
4. **Conditional Logic (Part 10):** Add a column called `vip_status`. If their `total_spent` is strictly greater than `1000`, set it to `"VIP"`. Otherwise, set it to `"Standard"`.
5. **Format:** Order the final report by `total_spent` descending. Show the results.

### My Solution:

```python
from pyspark.sql import SparkSession
from pyspark.sql.types import StructType, StructField, LongType, StringType, DoubleType
from pyspark.sql.functions import col, split, explode, size, array_contains, sum, when

spark = SparkSession.builder.appName("challenge_10").master("local[*]").getOrCreate()

spark.sparkContext.setLogLevel("ERROR")

# 1. Transactions Data (Purchases stored as a single string)
txn_schema = StructType([
    StructField("txn_id", LongType(), True),
    StructField("user_id", StringType(), True),
    StructField("purchased_items", StringType(), True)
])

txn_data = [
    (101, "User_A", "laptop,mouse,keyboard"),
    (102, "User_B", "monitor"),
    (103, "User_C", "mouse,cable,webcam"),
    (104, "User_A", "webcam,laptop")
]
txn_df = spark.createDataFrame(data=txn_data, schema=txn_schema)

# 2. Product Catalog Data
catalog_schema = StructType([
    StructField("product", StringType(), True),
    StructField("price", DoubleType(), True)
])

catalog_data = [
    ("laptop", 1200.00),
    ("mouse", 25.50),
    ("keyboard", 75.00),
    ("monitor", 300.00),
    ("cable", 15.00),
    ("webcam", 60.00)
]
catalog_df = spark.createDataFrame(data=catalog_data, schema=catalog_schema)

# print("Transactions DF:")
# txn_df.show(truncate=False)
# print("Catalog DF:")
# catalog_df.show()

## Challenge 12a: Splitting and Sizing (Easy)
split_size_df = (
    txn_df
    .withColumn("items_array", split(col("purchased_items"), ","))
    .withColumn("item_count", size(col("items_array")))
)
print("Challenge 12a: Splitting and Sizing (Easy)")
split_size_df.show(truncate=False)

## Challenge 12b: The Explode Filter (Medium)
split_explode_df = (
    txn_df
    .withColumn("single_item", explode(split(col("purchased_items"), ",")))
    .filter(col("single_item") == "webcam")
    .select("txn_id", "user_id", "single_item")
)
print("Challenge 12b: The Explode Filter (Medium)")
split_explode_df.show()

## Challenge 12c: The Revenue Engine (Boss Level)
revenue_engine_df = (
    txn_df
    .withColumn("product", explode(split(col("purchased_items"), ",")))
    .join(catalog_df, on="product", how="inner")
    .groupBy("user_id")
    .agg(sum(col("price")))
    .withColumnRenamed("sum(price)", "total_spent")
    .withColumn("vip_status", 
        when(col("total_spent") > 1000, 'VIP')
        .otherwise("Standard")
    )
    .orderBy(col("total_spent").desc())
)
print("Challenge 12c: The Revenue Engine (Boss Level)")
revenue_engine_df.show()
```
